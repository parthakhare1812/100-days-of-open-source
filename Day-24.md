# Day 24 - Fraud Detection Workflow

## Objective

Document the fraud detection process used in DriveLegal.

## Workflow Steps

1. OCR Extraction
2. Data Parsing
3. Validation
4. Fraud Analysis
5. Risk Scoring
6. Classification
7. Report Generation

## Fraud Indicators

- Missing Fields
- Invalid Formats
- Duplicate Records
- Data Mismatch
- Suspicious Patterns

## Deliverables

- Fraud Detection Diagram
- Workflow Documentation

## Learnings

- Fraud detection requires multiple validation stages.
- Risk scoring simplifies decision making.
- Visual documentation improves maintainability.
