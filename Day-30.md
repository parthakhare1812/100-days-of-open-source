# Day 30 - Database Schema Design

## Objective

Design the database schema for DriveLegal.

## Tables Designed

1. Users
2. Uploaded Documents
3. Verification Reports
4. Crash Predictions
5. Road Reports
6. Activity Logs

## Relationships

- User → Documents
- User → Predictions
- User → Road Reports
- Document → Verification Report

## Deliverables

- Database Schema Diagram
- Entity Documentation

## Learnings

- Good schema design improves scalability.
- Relationships are critical for data consistency.
- Database design is a key software engineering skill.
