# Day 3 - Exploring Real Open Source Contributions

## Objective
Understand how real open-source projects manage contributions and identify a beginner-friendly issue to work on.

## Repository Explored
- VMware Versatile Data Kit (VDK)
- Repository: https://github.com/vmware/versatile-data-kit

## Activities Completed

### 1. Explored GitHub Issues
- Learned how issues are used to track bugs, enhancements, and documentation tasks.
- Filtered issues using the "good first issue" label.

### 2. Selected an Issue
- Issue #3061: Collab Notebook: Processing data using SQL and local database

### 3. Analyzed the Issue
- Read the issue description.
- Checked labels and milestones.
- Reviewed discussion between contributors and maintainers.
- Determined that the task involves creating a Google Colab notebook based on an existing wiki page.

### 4. Learned
- How maintainers organize work.
- How contributors communicate before starting work.
- Why understanding project requirements is important before coding.
- The importance of reading issue discussions and project guidelines.

## Key Takeaways
- Not every "good first issue" is easy.
- Understanding the project is as important as writing code.
- Open-source contributions start with communication.
- Documentation and example notebooks are valuable contributions.

## Next Steps
- Contact maintainers for clarification.
- Explore the wiki page referenced in Issue #3061.
- Identify notebook structure and contribution requirements.
